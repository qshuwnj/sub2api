# AtlasCloud 多参考图视频合同

多参考图模式使用精确 SKU 和独立签名报价，不复用首帧图生合同。Wan 和 MiniMax
使用 `refers: [{url, type: "image"}]`；Seedance、Kling 使用 `reference_images`；
Grok 使用 `image_urls`。只接受经过校验的公网 HTTPS 图片 URL。

当前接通 12 个图片参考 SKU，默认时长覆盖 57 档官方清晰度。价格卡必须逐档登记
官网 calculate 证据、合同版本和固定售价。新增合同不修改已配置的文生视频或首帧
图生视频价格。提交继续使用原有签名、幂等键、财务预留和持久任务恢复链路。

## 未开放的工作流

- 参考视频和参考音频需要独立验证输入素材时长及计费；不能使用无素材的输出预览价。
- Kling 角色库、预设声音、文档解析和末帧不包含在当前图片参考价格合同内。
- 动作控制按参考视频时长计费，不使用用户选择的普通输出时长。
- 视频编辑需要输入与输出双向计费。
- Seedance 草稿补全依赖有效的已完成草稿 ID，继承草稿参数。
- 音频生成需要单独的持久任务和结算接口；TTS 千字符报价不能填成每次价格。
- 旧的 `Kling 3.0` 别名没有精确官方 SKU，不自动猜测 Standard/Pro 映射。

以上输入在供应商提交前拒绝；不得通过关闭签名报价、使用零价或宽泛模型别名开放。

## 验证

`atlas_reference_images_test.go` 使用官网只读报价快照，覆盖 57 个签名报价及原生
序列化组合，同时验证缺图、输入视频和私网图片引用被拦截。所有供应商传输均为空，
不会生成真实媒体或产生供应商费用。
